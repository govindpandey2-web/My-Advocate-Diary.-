✉️ Reminder — फोटो और Matter

Calendar JPG/PDF में Profile Photo या Band Logo में से कोई एक चुनें।

💾 Backup Storage

Backup को फोन में सुरक्षित रखें, Google Drive/Share से दूसरी जगह भेजें या पुराने Backup को वापस Import करें। App अपने local storage में automatic backup भी बनाता है।

Automatic local backup: हर बदलाव पर latest backup और दिन का backup local storage में रखा जाता है। रोज़ backup prompt भी दिख सकता है।

📅 Date Filter Backup

App के calendar filter की तरह तारीख चुनें — All / This Year / Last Year / Custom। नीचे के Download और Google Drive/Share बटन इसी चुनी हुई range का Backup बनाएँगे। File का नाम dd-mm-yyyy-hh-mm-ss Diary backup पैटर्न में बनेगा (Range चुनी हो तो नाम के अंत में Range भी जुड़ेगी)।

🗑 History Delete

तारीख range चुनें और तय करें क्या हटाना है। Delete से पहले अपने-आप एक Backup बनता है और Confirm code भी माँगा जाएगा।

🎨 App Layout

Scroll, sticky elements, history, JPG/Calendar, Dashboard boxes और Part layout यहाँ manage करें।

यहाँ APK में पहले से जोड़े गए Alternate App Icons में से Icon बदलें और ऐप खुलते समय Welcome Text सेट करें।
